# The sys library

This library contains essential functions for managing a Sinistra instance and other useful system functions.

| Libcall | Library | Call | Arity | Argument expectations | Return value | Side effects | Failure behaviour | Example |
| --- | --- | --- | ---: | --- | --- | --- | --- | --- |
| `sys.backup` | `sys` | `backup` | 0 | None. | `true` only when the timestamped backup is written and the configured durability level is fully confirmed; otherwise `false`. The boolean result is an intentional compatibility change from the previous `nil` return. | Synchronously saves a separate backup of the current in-memory itemstore using the configured durability mode. The filename is the configured itemstore name followed by the readable `YYYYMMDD-HHMMSS` timestamp suffix. If that name already exists, a deterministic numeric suffix (`_1`, `_2`, ...) is selected so an earlier backup is never replaced; the primary store is not replaced. The synchronous write pauses event-loop progress. | Missing persistence configuration or a write/durability failure sets `ERR_RUNTIME_PERSISTENCE` with operation, target-path detail when available, and executing-item provenance. `false` means durability was not fully confirmed; if failure occurs after atomic publication, the selected backup target may nevertheless contain the new snapshot. Success preserves any unrelated prior error. | `@ok = sys.backup;` |
| `sys.log{value}` | `sys` | `log` | 1 | Any value. Lists render as `#[...]`; item references as `&path`; nested strings are quoted and escape quotes, backslashes, and controls. Top-level strings are unchanged and nil produces no output. | `nil`. | Writes to the system log. | Rendering, allocation, malformed-value, or output-limit failures produce a deterministic diagnostic marker. | `sys.log{"player connected"};` |
| `sys.shutdown` | `sys` | `shutdown` | 0 | None. | `nil`. | Logs the request, marks the shutdown as safe, and stops the event loop so the engine can shut down cleanly and save the itemstore. | No failure is reported to Sinistra code. | `sys.shutdown;` |
| `sys.abort` | `sys` | `abort` | 0 | None. | `nil`. | Logs the request, marks the shutdown as unsafe, and stops the event loop without the normal itemstore save. | No failure is reported to Sinistra code. | `sys.abort;` |
| `sys.compile{source}` | `sys` | `compile` | 1 | `source` must evaluate to a string containing Sinistra source code; any non-string value, including a float, is invalid and is not converted to a string. | `true` when the source compiles and finishes with `error` equal to `nil`; `false` when the argument is invalid, compilation/setup fails, execution is interrupted, or execution leaves a non-`nil` error. | Compiles the source into a collision-safe temporary code item, executes it, ignores its ordinary return value, and deletes the temporary item on every execution outcome. Successful execution normalizes `error` and all structured error fields to `nil`; other item mutations remain. | Non-string input sets `ERR_RUNTIME_INVALIDARGS`; structured compiler diagnostics preserve the compiler diagnostic with `error.item = nil`; runtime errors from the generated temporary item may name that temporary item in `error.item` even after it has been deleted. Setup failures set their specific runtime error. Interrupted execution preserves a more specific error when present, otherwise sets `ERR_RUNTIME_SIGUSR1`. All failures return `false`. | `@ok = sys.compile{"foo = 42;"};` |
| `sys.exists{name}` | `sys` | `exists` | 1 | `name` must evaluate to a string or item reference; relative strings resolve from the executing item. Path strings are folded with ASCII `A`-`Z` to `a`-`z`; ordinary string values are unchanged. | `true` when the item exists; `false` when it does not exist or the argument is invalid. | None. | Invalid argument types set the runtime invalid-arguments error and return `false`. Invalid item names return `false` without setting an error. | `if sys.exists{@ref} then ...; endif;` |
| `sys.itemref{name}` | `sys` | `itemref` | 1 | `name` must be a string; relative names resolve from the executing item. ASCII case folding produces the canonical path. | Owned canonical root-relative item reference, including when dangling; `nil` for invalid names or allocation failure. | None. | Wrong types set `ERR_RUNTIME_INVALIDARGS`; invalid names return `nil`. | `@ref = sys.itemref{"player.name"};` |
| `sys.itemname{reference}` | `sys` | `itemname` | 1 | `reference` must be an item reference. | Owned canonical root-relative string; `nil` for invalid input or allocation failure. | None. | Wrong types set `ERR_RUNTIME_INVALIDARGS`. | `@name = sys.itemname{@ref};` |
| `sys.fetch{reference}` | `sys` | `fetch` | 1 | `reference` must be an item reference. | Owned clone of a value target, or explicit return from a code target invoked with ordinary zero-argument padding; `nil` when unresolved. | Executes code targets. | Invalid input sets `ERR_RUNTIME_INVALIDARGS`; dangling or missing targets return `nil` and preserve unrelated error state. A selected code target with malformed bytecode or insufficient VM capacity sets `ERR_RUNTIME_BYTECODE` and aborts the current interpretation. A selected value whose result cannot be cloned logs and aborts; it publishes `ERR_RUNTIME_INTERNAL` when the diagnostic can be published. | `@value = sys.fetch{@ref};` |
| `sys.call{reference, arguments}` | `sys` | `call` | 2 | `reference` must identify code and `arguments` must be a list. | Explicit return value from the target, or `nil` for invalid/missing/non-code targets. | Executes code with list elements in order; ordinary arity pads missing values and reports discarded excess under strict runtime contracts. | Invalid contracts set `ERR_RUNTIME_INVALIDARGS`; unresolved or existing non-code targets return `nil` and preserve unrelated error state. A selected code target with malformed bytecode or insufficient VM capacity sets `ERR_RUNTIME_BYTECODE` and aborts the current interpretation. A selected code target whose arguments cannot be cloned logs and aborts; it publishes `ERR_RUNTIME_INTERNAL` when the diagnostic can be published. | `@result = sys.call{@ref, #[1, 2]};` |
| `sys.delete{name}` | `sys` | `delete` | 1 | `name` must evaluate to a string or item reference; string paths use ASCII case folding, including relative paths. | `true` when an existing unpinned target and its descendants are deleted; `false` for absent/malformed names, pinned targets, or protected targets. A wrong argument type returns `nil`. This boolean result is an intentional pre-0.8 compatibility/API change from the former `nil` result. | Atomically deletes the named item and its children when it exists. | Invalid argument types set `ERR_RUNTIME_INVALIDARGS` with the detailed argument message and return `nil`. Valid absent or malformed names return `false` without changing an unrelated prior error. If the target or any descendant is execution-pinned, deletion is refused atomically, returns `false`, and sets `ERR_RUNTIME_INUSE` with canonical target detail and executing-item provenance. The runtime-reserved `error` namespace—including its root, known, unknown, and future descendants, including relative paths resolving within it—remains protected; attempts return `false`, preserve the subtree, and retain the `ERR_RUNTIME_INVALIDITEM` protected-item diagnostic. | `@deleted = sys.delete{@ref};` |
| `sys.nthname{name, index}` | `sys` | `nthname` | 2 | `name` must evaluate to a string or item reference; `index` must evaluate to a non-negative integer child index. | The child item name at `index`, or `nil` when there is no such item. | None. | Invalid argument types or a negative index set the runtime invalid-arguments error and return `nil`. Missing or invalid item names, out-of-range indexes, and allocation failure return `nil` without setting an error. | `@child = sys.nthname{@ref, 0};` |
| `sys.rootname{index}` | `sys` | `rootname` | 1 | `index` must evaluate to a non-negative integer root-item index. | The root item name at `index`, or `nil` when there is no such item. | None. | Invalid argument types or a negative index set the runtime invalid-arguments error and return `nil`. Out-of-range indexes and allocation failure return `nil` without setting an error. | `@root = sys.rootname{0};` |
| `sys.save` | `sys` | `save` | 0 | None. | `true` only when the configured primary itemstore is written and the configured durability level is fully confirmed; otherwise `false`. | Synchronously checkpoints the current in-memory item tree to the configured primary itemstore path. The write pauses event-loop progress. Runtime mutations made after the call returns are not included in that completed snapshot. | Missing persistence configuration or a write/durability failure sets `ERR_RUNTIME_PERSISTENCE` with operation, target-path detail when available, and executing-item provenance. `false` means durability was not fully confirmed; if failure occurs after atomic replacement, the primary target may nevertheless contain the new snapshot. Success preserves any unrelated prior error. | `@ok = sys.save;` |
| `sys.thisitem` | `sys` | `thisitem` | 0 | None. | An owned string containing the fully qualified name of the currently executing code item. A top-level item returns its own name. | None. | A defensive invocation without a current item, or string allocation failure, returns `nil` without changing `error`. Success preserves unrelated prior errors. | `@self = sys.thisitem;` |
| `sys.parentitem` | `sys` | `parentitem` | 0 | None. | The fully qualified namespace-parent name, or `nil` when the executing item is top-level. Namespace parent is independent of the call-stack caller. | None. | A defensive invocation without a current item, a top-level current item, or string allocation failure returns `nil` without changing `error`. Success preserves unrelated prior errors. | `@namespace = sys.parentitem;` |
| `sys.calleritem` | `sys` | `calleritem` | 0 | None. | An owned string containing the fully qualified name of the immediate synchronous Sinistra caller, or `nil` for a direct interpreter entry. During nested calls it reports the item whose frame invoked the current item. | None. | Missing caller context or allocation failure returns `nil` without changing `error`. Success preserves unrelated prior errors. A temporary item run by `sys.compile` reports the item that invoked `sys.compile`; an ordinary item called by that temporary item reports the temporary item's generated name. | `@caller = sys.calleritem;` |
| `sys.itemtype{name}` | `sys` | `itemtype` | 1 | `name` must be a string or item reference. Relative strings resolve from the currently executing item. | Exactly `"code"`, `"nil"`, `"bool"`, `"int"`, `"float"`, `"string"`, `"itemref"`, or `"list"`; `nil` when the name is absent or syntactically invalid. | None. | A wrong type returns `nil` and sets `ERR_RUNTIME_INVALIDARGS` with call-specific detail and current-item provenance. Invalid/missing names and allocation failure return `nil` without changing `error`; success preserves unrelated prior errors. | `@kind = sys.itemtype{@ref};` |
| `sys.paramcount{name}` | `sys` | `paramcount` | 1 | `name` must be a string or item reference. Relative strings resolve from the currently executing item. | The code item's declared parameter count as an integer from `0` through `255`; `nil` for an invalid or missing name, a value item, or a code item without a readable two-byte locals/parameters header. | Reads the declared count from the code item's bytecode header without executing it. | A wrong type returns `nil` and sets `ERR_RUNTIME_INVALIDARGS` with call-specific detail and current-item provenance. Other `nil` outcomes and success preserve unrelated prior errors. | `@arity = sys.paramcount{@ref};` |
| `sys.source{name}` | `sys` | `source` | 1 | `name` must be a string or item reference. Relative strings resolve from the currently executing item, and path strings use ASCII case folding. | An owned string containing the code item's exact `source.sin` bytes, including an empty string for an empty file. Invalid/missing names and value items return `nil`. | Reads `<srcroot>/<canonical item layers>/source.sin` in binary mode without executing or modifying the item. Results are limited to `SIN_MAX_STRING_BYTES`. | A wrong type returns `nil` and sets `ERR_RUNTIME_INVALIDARGS`. If an existing code item's source cannot be returned, the call sets `ERR_RUNTIME_SOURCE` with item/path or I/O detail and current-item provenance, then returns an owned empty string where allocation permits. This includes unconfigured source roots, missing files, I/O/allocation failures, oversized files, and embedded NUL bytes. Successful and `nil` introspection outcomes preserve unrelated prior errors. | `@text = sys.source{@ref};` |
| `sys.childcount{name}` | `sys` | `childcount` | 1 | `name` must be a string or item reference. Relative strings resolve from the currently executing item. | Immediate-child count as an integer; an existing leaf returns `0`, while an absent or syntactically invalid name returns `nil`. | Bounds `sys.nthname{name, index}` enumeration of the current tree; ordering is not promised across runtime restarts. | A wrong type returns `nil` and sets `ERR_RUNTIME_INVALIDARGS` with call-specific detail and current-item provenance. Invalid/missing names return `nil` without changing `error`; success preserves unrelated prior errors. | `@count = sys.childcount{@ref};` |
| `sys.rootcount` | `sys` | `rootcount` | 0 | None. | Number of root namespace items as an integer. | Bounds `sys.rootname{index}` enumeration of the current tree; ordering is not promised across runtime restarts. | Success preserves unrelated prior errors. | `@count = sys.rootcount;` |
| `sys.version` | `sys` | `version` | 0 | None. | An owned copy of the raw [`SINVERSION`](../../src/version.h) string. | None. | Allocation failure returns `nil` without changing `error`; success preserves unrelated prior errors. | `@engine_version = sys.version;` |
| `sys.now` | `sys` | `now` | 0 | None. | Signed integer Unix-epoch milliseconds, saturated at the signed integer limits on theoretical overflow. | Reads the libuv wall clock. | Unexpected clock-query failure logs an internal diagnostic and returns integer `0` without changing `error`; success preserves unrelated prior errors. | `@timestamp_ms = sys.now;` |
| `sys.monotime` | `sys` | `monotime` | 0 | None. | Signed integer monotonic milliseconds from an unspecified OS origin. Only differences are meaningful; values do not decrease within one process and theoretical overflow clamps to the signed maximum. | Reads libuv's high-resolution monotonic clock. | Success preserves unrelated prior errors. | `@started_ms = sys.monotime;` |
