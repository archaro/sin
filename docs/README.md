# Sinistra Documentation Index

## What is Sinistra?

A persistent, dynamically extensible runtime intended for building MUD-like worlds, with its own language, compiler and bytecode VM.

- [History](history.md): The why and whence of Sinistra.

## What is unusual about it?

The world is fundamentally an item tree. Items contain values or executable code; state lives in memory while running and is persisted to the itemstore; running code can compile and install new code.
